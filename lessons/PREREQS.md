# Prerequisites & Setup

Setup is now split per lesson, so you only install what each lesson needs, when
you need it. Complete everything **before Lesson 5** — Lessons 2–3 run entirely
in the browser, but setting up early means you won't lose class time to
installation.

## What to set up, and when

| When | What | Where |
| ---- | ---- | ----- |
| Before Lesson 4 | Node.js, Foundry, code editor (+ Codespaces fallback) | [`04-foundry-local/PREREQS.md`](./04-foundry-local/PREREQS.md) |

> If any step fails and you can't fix it before class, use the
> **[GitHub Codespaces fallback](./04-foundry-local/PREREQS.md#fallback-github-codespaces)**
> so one broken laptop doesn't stall the room.

## Full self-check before Lesson 4

- [ ] MetaMask installed, Sepolia added, test ETH received
- [ ] `node --version` prints v20+
- [ ] `forge --version` works
- [ ] `anvil` starts and prints a list of dev accounts (Ctrl-C to stop)
